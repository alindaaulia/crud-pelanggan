# CRUD Pelanggan (PHP & PDO)

Aplikasi CRUD sederhana untuk mengelola data pelanggan menggunakan PDO, dan MySQL.

## Fitur
- Tambah, lihat, edit, dan hapus data pelanggan.
- Pencarian berdasarkan nama atau email.
- Validasi input dan pagination.
- Keamanan menggunakan prepared statement dan CSRF token.
